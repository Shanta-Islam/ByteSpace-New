# ByteSpace — Learning Platform

A modern and responsive learning platform landing page built with Next.js, TypeScript, Tailwind CSS, and React Icons.

## 🚀 Live Demo

[Live Demo](https://byte-space-new-olive.vercel.app/)


## ✨ Features

- Responsive landing page
- Modern hero section
- Student-focused learning platform design
- Course categories section
- Popular courses section
- Instructor section
- Testimonials
- Call-to-action sections
- Responsive navigation
- Login page
- Signup page
- Custom 404 page
- Reusable React components
- Responsive design for mobile, tablet, and desktop

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- Next/Image
- Next/Link
